# Firmware 1.26

This version improves audio buffering and keeps streaming, the Web UI and MQTT responsive.

- More efficient RTSP/TCP sending keeps the Web UI and other connected clients responsive.
- Improved handling of queued audio and a larger 64 KiB internal reserve for packet sizes up to 2048 samples, with the existing RTP packet sizes.
- Microphone auto-recovery follows capture activity, with a cooldown between recovery attempts.
- Packet rates in the Web UI, API and MQTT reflect the most recent ten seconds.
- MQTT updates use bounded socket writes and are coalesced after audio processing.
- Arduino ESP32 core updated to 3.3.12.
- WiFiManager debug output disabled for quieter logs and a smaller firmware image.
- The default access-point option is now named **Default connection** for clearer wording; connection behavior is unchanged.
